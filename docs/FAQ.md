# FAQ

## Почему бесплатный доступ выдаётся по общему паролю, а не персонально?

Так решено сознательно для текущей стадии проекта: один пароль
(`BOT_FRIENDS_SHARED_CODE`) на всех приглашённых, без учёта, кто именно его
ввёл. Следствие — отозвать доступ одному конкретному клиенту нельзя, только
сменить пароль для всех разом. Персональные коды — не то же самое, что
персональный учёт клиентов: `customer_id` у каждого клиента свой (Telegram
user id), различаются только *права на получение* доступа.

## Что такое тест-коды (`test10m`, `test1h`, `test1w`, `test1mo`)?

Отдельные от `BOT_FRIENDS_SHARED_CODE` пароли с искусственно короткими
сроками жизни (10 минут, 1 час, 1 неделя, 1 месяц) — для ручной проверки
поведения на грани истечения доступа, без ожидания реального
`friends_plan_duration_days`. Реализованы в
`application/use_cases/redeem_friend_code.py`, помечены `# TEST/DEBUG` —
предполагается их удаление или вынос за флаг конфигурации до продакшена
для внешних пользователей.

## Я ввёл тест-код, а бот ответил про «текущий срок доступа длиннее» — почему?

`spiritvpnd` не укорачивает `expires_at` — если у клиента уже есть активный
доступ с более поздним сроком истечения, чем даёт введённый код, запрос
отклоняется (`ExpiryRegression`). Это не баг: правило специально не
позволяет случайно сократить уже выданный доступ. Решение — либо взять код
с бо́льшим сроком, либо дождаться истечения текущего.

## В интерфейсе видно `BRIDGE`/`FREEDOM` рядом со ссылкой — что это?

Внутренний `kind` типа ссылки в `spiritvpnd` и SNI ноды, из которой она
выдана — показывается только при включённом `DEBUG_SHOW_LINK_DETAILS` в
`static/index.html`, для отладки. UUID ссылки при этом не раскрывается —
парсится только `sni=` из query-параметров самого VLESS-URI. В обычном
(не debug) режиме клиент видит только состояние ссылки и её содержимое
через кнопку «Скопировать».

## Тариф написан «Безлимит», но в системе всё равно есть `quota_bytes` — это ошибка?

Нет: `display_as_unlimited` в `Plan` — только про то, что показывается в
интерфейсе. Реальная квота трафика на ноду (`quota_bytes`), которая уходит
в `spiritvpnd`, от этого флага не зависит и остаётся конечной.

## Почему в проекте не используются моки, а только фейковые реализации портов?

Фейки (`tests/unit/application/fakes.py`) реализуют тот же `Protocol`, что
и настоящий адаптер, — значит, ошибка несовпадения интерфейса ловится на
уровне типов (`mypy`), а не только в рантайме теста. Подробнее в
[Тестировании](TESTING.md).
